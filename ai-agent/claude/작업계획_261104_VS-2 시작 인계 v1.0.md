## 4. VS-2 작업 지시서 (이슈 #4)

### 4.1 목표와 완료 기준
이슈 #4 "기대 결과"와 같다. 요약하면 **TSL 기준 단어 500개(뜻·예문 포함)가 `words` 표에 적재되고, 시드를 다시 실행해도 500행이며, 예문에 영단어가 그대로 들어 있고, 본인이 샘플을 검수하고, 출처(CC BY-SA 4.0)가 표기된다.** 추정 4시간 + 작성 시간.

### 4.2 시작할 때 본인에게 먼저 결정받을 것 (결정 후 ADR 로 기록)

**단어 선정 기준**: TSL 은 약 1,200단어의 토익 서비스 목록이고 `the`, `of`, `be` 같은 기초 기능어도 포함할 가능성이 크다(내용은 직접 확인 전 추정). 500개를 어떻게 고를까?

| 안 | 내용 | 장단점 |
|---|---|---|
| A | TSL 빈도 상위 500개를 그대로 | 근거가 단순하고 설명하기 쉬움. 기초 단어가 섞여 학습 가치가 낮음 |
| **B (추천)** | 기초 기능어·초급 단어를 제외하고 TSL 빈도 순으로 500개 | 학습 가치가 높음. 제외 기준을 설명해야 함 |

결정되면 `frequency_rank` 는 **우리 서비스 안에서의 학습 순서 1~500**으로 다시 매긴다(무료 범위 = rank ≤ 250). 원래 TSL 순위와 제외한 단어 목록은 `data/words/README.md` 에 선정 기록으로 남긴다.

### 4.4 데이터 규격 (`data/words/toeic_500.csv`)

UTF-8, 첫 줄 머리글. 열 6개 (`words` 표와 같은 이름): `frequency_rank, headword, part_of_speech, meaning_ko, example_en, example_ko`. 쉼표·따옴표가 있는 칸은 CSV 인용 규칙을 따른다(파이썬 `csv` 모듈 사용).

| 열 | 규칙 |
|---|---|
| frequency_rank | 1~N 연속 정수, 중복·누락 없음 (1 이 가장 먼저 배울 단어) |
| headword | 소문자. 영문자, 공백, 하이픈만 허용(복합 표현 가능). 중복 불가 |
| part_of_speech | `n.` `v.` `adj.` `adv.` `prep.` `conj.` `phr.` 중 하나 `[설계 확정]` |
| meaning_ko | 토익 문맥 우선 1~3개 뜻, 쉼표로 구분, 60자 이하 |
| example_en | 토익 문맥(사무·회의·계약·출장·마케팅·고객 등) 한 문장, 6~16단어. **headword 가 활용 없이 그대로** 들어 있어야 함(대소문자 무시, 단어 경계 기준). 동사는 원형이 자연스러운 문장(조동사 뒤, 복수 주어, to부정사 등)으로 쓴다 |
| example_ko | 자연스러운 번역 한 문장, 100자 이하 |

**검증 규칙(시드 스크립트가 줄 번호와 함께 보고, 하나라도 실패하면 적재하지 않고 종료 코드 1)**: 열 수·이름 일치, 빈 값 없음, headword 중복 없음, rank 중복·누락 없음, 소문자 규칙, 품사 허용 목록, 길이 제한, 예문 포함 검사.

**적재 규칙**: 한 트랜잭션에서 `headword` 기준 upsert. `frequency_rank` 가 UNIQUE 라서 순위를 서로 바꾸는 변경은 한 번에 갱신하면 충돌한다 → 기존 순위를 임시로 크게 밀었다가 최종값으로 갱신하는 2단계로 처리한다. DB 에 있지만 CSV 에 없는 단어가 있으면 조용히 두지 말고 오류로 알린다(나중에 `user_words` 가 참조하므로 삭제 금지).

**옵션**: `--dry-run`(검증만), `--target dev|test`(기본 dev).

### 4.5 TSL 입수 계획

1. `web-fetch` 에이전트로 https://newgeneralservicelist.com/toeic-service-list 를 읽어 **다운로드 링크, 파일 형식, 라이선스 문구**를 확인한다 (환경 분석서에는 검색 요약만 있고 원문은 못 읽었다).
2. 승인 범위의 다운로드 1건: "TSL 1.2 with basic statistics" 파일(빈도 통계 포함)을 `ai-agent/uploads/TSL/` 에 저장하고 출처·라이선스 안내 파일을 같이 둔다.
3. 형식이 엑셀(.xlsx)이면 읽을 패키지(예: openpyxl) 설치가 필요하다 → 구현 계획서 11장 목록에 없으므로 **본인 승인을 받는다**.
4. **대안(받을 수 없거나 읽을 수 없을 때)**: Claude 가 토익 빈출 단어를 직접 골라 작성하고, 확인 가능한 범위에서만 TSL 과 대조하며, 한계를 `data/words/README.md` 와 일지에 정직하게 적는다. 발표에서는 "TSL 기반"이라고 말하지 않는다.
5. 저작권: 시중 단어장(해커스 등)의 내용은 **참고하지도, 옮기지도 않는다**(본인 결정).
