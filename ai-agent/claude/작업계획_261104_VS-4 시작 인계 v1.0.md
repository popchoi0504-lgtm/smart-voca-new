## 2. VS-3 에서 이미 만들어 둔 것 (VS-4 가 재사용)

- `core_logic/sm2.py`: `calculate_next(Sm2State, quality)` 순수 함수. 3점 미만이면 초기화(난이도 계수 유지). `core_logic/quality.py` 에는 플래시카드 변환표만 있다 → **퀴즈 결과(correct/wrong/revealed + 힌트 단계) → 점수 변환은 FR-SRS-03 제안(힌트 없이 정답 5, 1단계 후 4, 2단계 후 3, 3단계/오답 1~2)을 근거로 quality.py 에 추가**한다.
- `services/study_service.py`: 시간은 `now_utc()` 한 곳에서만 읽는다(테스트가 `monkeypatch.setattr("app.services.<모듈>.now_utc", ...)` 로 시계를 옮김). 요금제 범위 계산 `_plan_word_limit`, 한국 날짜 계산 패턴을 참고. 퀴즈 서비스에서도 같은 방식을 쓸 것.
- `models/user_word.py`(복습 상태), `models/review_log.py`(추가만 하는 기록; `activity_type='quiz'`, `result`∈correct/wrong/revealed, `max_hint_level` 0~3 컬럼이 이미 있다 → **표 변경 불필요할 가능성이 큼**, 설계서와 대조해 확인).
- 오류 코드 `WORD_NOT_LEARNED`(아직 학습하지 않은 단어로 퀴즈 시도, 409)는 인터페이스 정의서에 정의되어 있고 아직 쓰이지 않았다.
- `tests/test_study.py` 의 `words`·`client`·`clock` 픽스처 패턴 재사용(복습 대상은 user_words 를 직접 채우거나, 평가 후 `clock.advance(days=1)`).

## 3. VS-4 작업 순서 (구현 계획서 4장 기준, 세부는 새 세션이 문서를 읽고 확정)

1. 상태 점검(`git status`, 테스트 112개, DB 접속) 후 개념 설명: ① 정답을 브라우저에 보내지 않는 이유, ② 힌트를 날짜·회원마다 같게(결정적) 만드는 이유, ③ 하루 한 번만 SM-2 반영·이후 연습 처리 규칙(IF-4), ④ `revealed` 를 오답과 따로 기록하는 이유(기획서 D-5).
2. 핵심 로직 + 단위 테스트 먼저(가장 두껍게): `core_logic/hints.py` — 철자 섞기(원형과 다르게, 3글자 이하·같은 글자뿐인 단어는 건너뜀, 공백·하이픈 고정), 빈칸(공개 글자는 정답의 같은 위치 글자), 첫 글자 공개, 같은 날·같은 회원·같은 단어면 같은 결과.
3. 서비스·API: `services/quiz_service.py`, `routers/quiz.py` (queue, hint, answer). 문제 목록에 정답 영단어 없음, 오답 시 정답 미공개, 정답 확인은 `revealed`, 같은 단어 두 번째 제출은 연습(SM-2 미반영), 복습 대상은 오래 밀린 순(FR-SRS-04), 한 세션 분량 제한(FR-SRS-05).
4. 화면: Quiz, HintPanel, 홈 화면의 "복습 퀴즈는 VS-4 에서" 안내 문구를 실제 링크로 교체.
5. 확인: pytest, 일부러 고장 낸 코드를 테스트가 잡는지, 실서버 시나리오(대표에게 서버 켜도 되는지 먼저 알림), 대표 브라우저 확인.
6. 문서: 질문 모음(파일 지도, 2.7 루트, Q&A), 이슈 #6 체크, 일지, 커밋·푸시 승인 요청.

## 4. 운영 규칙 (그대로 유지)

- **이해 확인 질문을 하지 않는다.** 설명 의무(무엇을/왜/대안을 쉬운 말로)와 발표 Q&A 갱신은 한다.
- 커밋·푸시·`gh issue close` 는 대표 승인 후. 커밋 전 `.env` 비밀값 검색, 커밋 메시지 끝에 `(#6)`. 이슈 닫기는 자동 권한 검사에 막힐 수 있다 → 막히면 우회하지 말고 대표에게 안내(대표가 승인하고 재시도하면 통과한 적 있음).
- 윈도우 경로가 든 파일은 Write/Edit 도구로 쓴다(Git Bash 의 heredoc 에서 역슬래시 사고 전례).
- 뜻·예문 등 문장은 저장 전에 문법 점검. 시각은 `date` 로 확인.
- 스크립트 실행 시 `PYTHONPATH=.` 가 필요할 수 있다(`app` 모듈 인식).
