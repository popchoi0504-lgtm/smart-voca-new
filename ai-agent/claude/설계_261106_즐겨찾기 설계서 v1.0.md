# 즐겨찾기(별표) 설계서

**파일 위치**: `ai-agent/claude/설계_261106_즐겨찾기 설계서 v1.0.md`
**작성일**: 2026-11-06
**버전**: v1.0
**설명**: 단어에 별표를 달아 모으고, 모은 단어만 골라 다시 학습하는 기능(이슈 #22)의 요구·표·API·화면·결정을 정리한 문서

---

## 1. 배경과 요구

대표 요청(2026-11-06): "단어 배울 때 즐겨찾기 기능이 있었으면. 별표를 누르면 수집되게." 이어서 다음 3가지를 결정했다.

1. 모은 단어만 골라 **다시 학습하는 모드**도 넣는다.
2. 무료 범위(250개) 밖의 잠긴 단어는 **별표를 못 누르게** 한다.
3. **목록에서도 별표를 해제**할 수 있다.

## 2. 표: `favorites`

| 컬럼 | 타입 | 필수 | 설명·제약 |
|---|---|---|---|
| user_id | bigint | Y | FK → users.id, 회원이 지워지면 함께 삭제(CASCADE). PK 의 일부 |
| word_id | bigint | Y | FK → words.id. PK 의 일부 |
| created_at | timestamptz | Y | 별표를 단 시각 |

- (user_id, word_id) 가 기본 키다. 같은 단어에 별표가 두 번 달릴 수 없다.
- **행이 있으면 별표 켜짐**, 없으면 꺼짐. `user_words`(학습 여부)와 **독립**이다: 아직 배우지 않은 카드에도 별표를 달 수 있다.
- Alembic 변경 파일: `e9436477b39c_create_favorites.py`.

## 3. API (상세는 인터페이스 정의서 4.10)

| 메서드·주소 | 설명 |
|---|---|
| `GET /api/favorites` | 내 즐겨찾기 전체(최근에 단 순). 각 항목에 `is_locked` |
| `GET /api/favorites/study?limit=` | 다시 학습용 단어. 무작위, 최대 20개, 잠긴 단어 제외 |
| `PUT /api/favorites/{word_id}` | 별표 켜기(204, 이미 켜져 있어도 성공) |
| `DELETE /api/favorites/{word_id}` | 별표 끄기(204, 없어도 성공) |

## 4. 화면

- 플래시카드·즐겨찾기 학습 카드: **카드 오른쪽 위 모서리**에 별표(☆/★).
- 퀴즈: 정답이 공개된 뒤에만 카드 오른쪽 위에 별표. 단어가 곧 정답이라 미리 보이면 철자가 노출되기 때문이다(AD-7).
- `/favorites`: 목록, 별표로 해제, "즐겨찾기 단어 다시 학습" 버튼. 상단 메뉴에 "즐겨찾기".
- `/favorites/study`: 카드를 넘겨 보는 연습. 평가 버튼이 없고 서버에 아무것도 기록하지 않는다.

## 5. 설계 결정 (배경 / 대안 / 근거)

| # | 결정 | 대안 | 근거 |
|---|---|---|---|
| F-1 | 별표는 별도 표 `favorites` | `user_words` 에 `is_favorite` 컬럼 추가 | `user_words` 는 "배운 단어"만 행이 생긴다(DD-3). 안 배운 카드에도 별표를 달 수 있어야 하므로 독립 표가 맞다 |
| F-2 | 무료 범위 밖 단어는 켜기 403(`PLAN_LIMIT_EXCEEDED`) | 켜는 건 허용하고 학습만 막기 | 대표 결정. 플래시카드 학습 제한(DD-5)과 같은 기준을 서버가 한곳(`_plan_word_limit`)에서 계산 |
| F-3 | 이용권이 끝나도 기존 별표는 유지, 목록에 `is_locked`, **해제는 항상 가능** | 만료 때 별표 삭제 | 재가입(재구매) 시 모은 단어가 남아 있어야 하고, 해제까지 막으면 사용자가 갇힌다 |
| F-4 | 다시 학습은 **연습**: `review_logs`·`user_words` 를 건드리지 않음 | 평가 결과를 SM-2 에 반영 | 즐겨찾기 학습은 "골라서 보는" 용도라 복습 일정을 흔들면 오늘 할 일이 꼬인다. 확인 퀴즈(#21)와 같은 방침 |
| F-5 | 켜기·끄기는 멱등(여러 번 눌러도 성공), 켜기는 `ON CONFLICT DO NOTHING` | 중복이면 409 | 빠르게 두 번 눌러도 오류 없이 한 행만 남고, 화면은 낙관적으로 먼저 바꿨다가 실패 시 되돌리기만 하면 된다 |
| F-6 | 목록은 쪽 나누기 없이 전체 | 쪽 나누기 | 전체 단어가 2,000개라 한 회원의 최대치도 작다(#20 과 같은 판단) |
| F-7 | 다시 학습은 서버가 무작위로 뽑음(`ORDER BY random()`) | 화면에서 섞기 | 회원당 행이 적어 비용이 작고, 잠긴 단어 제외를 서버가 보장한다 |

## 6. 테스트

`tests/test_favorites.py` 11개: 담기·목록 순서, 중복 담기, 해제·재해제, 없는 단어 404, 무료 범위 경계(250 허용·251 거부), 프리미엄 전체 허용, 이용권 만료 후 잠김·학습 제외·해제 가능, 회원별 분리(남의 별표 삭제 불가), 학습 단어 수·limit 검사, 학습 기록 미변경, 로그인 필요.

## 7. 미결 사항

- 퀴즈 카드의 별표는 정답 공개 후에만 보인다. 문제를 풀기 전에 표시하고 싶다면 "철자 수 힌트"와의 충돌을 먼저 검토해야 한다.
- 즐겨찾기 학습에 평가(몰랐음/알았음) 버튼을 붙여 별표 자동 해제를 하는 기능은 이번 범위 밖이다.
